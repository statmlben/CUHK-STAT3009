# STAT3009 Machine Learning II · Quarto edition

This deck continues from `slides/Lec-ML-quarto/`. It introduces generalization
through familiar recommender baselines, motivates validation with a memorization
example, and connects holdout validation to the Netflix Prize data split. The
final section extends one probe set to K-fold cross-validation.

The deck reuses the shared STAT3009 theme and the ML-specific styles from
`slides/Lec-ML-quarto/ml.scss`.

## Render

```bash
quarto render S.qmd
```

Open `S.html` in a browser. Use the arrow keys to advance through builds, `S` for
speaker view, and `B` to pause the screen. The generated HTML is self-contained.
